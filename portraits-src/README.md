# Portrait sources (not published)

`remote/` holds the publisher-hosted miniature photos downloaded by `scripts/cutout-portraits.py --remote`
(via the **Portrait cutouts** workflow), plus `preview.png`, which shows each original next to its cutout.
These files are for review only and are not copied to the live site. Miniature imagery © Blizzard
Entertainment / Archon Studio; the publishers retain all rights.
