# Faction emblems

Painted faction emblems from the 2026 Core Rules PDF (StarCraft-TMG_EN.pdf), extracted with `pdfimages` and their own transparency masks, then trimmed. All rights remain with the publisher.

| File | PDF page | Where it appears in the book |
|---|---|---|
| terran.png | 98 (printed 96) | Terran unit list header |
| zerg.png | 101 (printed 99) | Zerg unit list header |
| protoss.png | 106 (printed 104) | Protoss unit list header |

Used on the home screen faction cards and as the faded mark behind each commander in VS. They replace the flat traced logos in `uploads/*logo.png`.
