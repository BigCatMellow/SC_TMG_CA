# Source: 2026 Core Rules miniature portraits

These are **the original painted miniature JPEGs embedded in the publisher's 2026 Core Rules**, PDF viewer pages 98–108. The [source manifest](source-manifest.json) maps all 22 files to a unit ID, printed page, PDF page, original image xref and SHA-256 checksum.

The checked-in photos are copied byte-for-byte from the embedded PDF images. Run `python scripts/extract-pdf-miniatures.py --check` to validate. To reproduce using the official book, install PyMuPDF and run `python scripts/extract-pdf-miniatures.py`. This refuses to extract from another PDF edition without a deliberate source review.
